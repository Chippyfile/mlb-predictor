# multi-sport-predictor

Frontend for the Formula 2 prediction system.

- **Deployed:** https://mlb-predictor-beta.vercel.app/
- **API:** https://sports-predictor-api-production.up.railway.app
- **Backend repo:** ~/Desktop/sports-predictor-api (Chippyfile/sports-predictor-api)

Sports live under `src/sports/<sport>/`; `src/components/Shared.jsx` holds
the AccuracyDashboard, HistoryTab and ParlayBuilder used by all five.

Runbooks for the weekly NFL and NCAAF routines are in the backend repo
under `claude/`.
